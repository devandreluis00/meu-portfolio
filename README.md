# Portfólio Pessoal | André Luis

Um portfólio web simples, moderno e responsivo desenvolvido para apresentar minha trajetória, projetos e tecnologias. O foco deste projeto é refletir minha transição para a área de Back-end[cite: 1], destacando minhas experiências e habilidades.

## 🚀 Funcionalidades

*   **Alternância de Tema:** Suporte nativo para Tema Escuro (padrão) e Tema Claro.
*   **Internacionalização:** Botão de tradução em tempo real (Português / Inglês) sem necessidade de recarregar a página.
*   **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops utilizando Flexbox e CSS Grid.
*   **Animações Suaves:** Efeitos de hover nos cartões e animações CSS puras no hero section.

## 🛠️ Tecnologias Utilizadas (Portfólio)

*   HTML5
*   CSS3 (Variáveis, Flexbox, Grid, Media Queries)
*   JavaScript Vanilla (Manipulação de DOM, LocalStorage/States)
*   [Devicon](https://devicon.dev/) (Ícones das stacks e redes sociais)

## 💻 Minha Stack Principal (Back-end)

Atualmente focado em arquitetura e desenvolvimento server-side, utilizando:

*   MySQL
